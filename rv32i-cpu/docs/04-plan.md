## 0. 目标

在 FPGA 上实现 **RV32I 五级流水线 CPU**，能跑 C 程序并通过 **UART** 打印结果。
定位：求职作品，目标岗位 **FPGA 工程师**。

## 1. 完成标准（分层）

```
Tier 1 及格   仿真跑通 RV32I 子集 + 汇编程序 + 少量 C 程序自测
Tier 2 目标   FPGA 上板，跑 C 程序，UART 打印结果          ← “够了”
Tier 3 加分   Dhrystone 等基准 + 性能/资源数据 + 中断/显示
```

## 2. 已定决策

| 项 | 决定 |
| --- | --- |
| 流水线 | 5 级 |
| 指令集 | RV32I 子集（ADD…JALR/LUI/AUIPC） |
| 输出 | **UART**（自己写 UART 模块 + MMIO） |
| 调试 | ILA（Vivado，仅调试，不打印） |
| 不碰 | AXI / PS、Cache、分支预测、中断、显示（显示仅在 Tier 3） |
| 板子 | Xilinx Zynq-7000 **XC7Z020**（当纯 FPGA/PL 用） |

## 3. 关键设计点（提前知道，少踩坑）

- **UART 需要 MMIO**：C 程序打印 = `printf → putchar → 向某地址 store → 地址译码选中 UART → 发送`。
  所以 CPU 的**存储路径要做地址译码**，把 UART 映射到一个地址（如 `0x1000_0000`）。
- **跑 C 程序还需要**：RISC-V 工具链、链接脚本、启动代码（`crt0`）、内存（imem/dmem，可用 BRAM）。
