## 素材 1：RISC-V 定长指令简化流水线

**放哪**：第 1 章（绪论）／ISA 简介

**论点**：
> ISA 是软硬件之间的接口。RISC-V 选择**定长（32 bit）+ 规整**，用一点代码密度换取**译码与流水线的简单**——这正是本项目能用清晰的五级流水线实现它的原因。

**例子**：同一条 `a = b + 1;` 在三个层级的样子
```
C        a = b + 1;
汇编     mov 0x804a01c,%eax / add $0x1,%eax / mov %eax,0x804a018   （x86）
机器码   a1 1c a0 04 08 / 83 c0 01 / a3 18 a0 04 08
```
RISC-V 近似：
```
lw   t0, 0(t1)
addi t0, t0, 1
sw   t0, 0(t2)
```

**对比（写成权衡，不是褒贬）**：

| | RISC-V 定长 | x86 变长 |
| --- | --- | --- |
| 译码 | 简单、规整 | 复杂（需扫描指令边界） |
| 流水线 | 好做 | 难做（预译码/µop cache） |
| 代码密度 | 略差 | 好 |
| 取向 | 简单/规整 | 兼容性/密度 |

**防坑**：不要写成“x86 落后 RISC-V 先进”。要写成 **design tradeoff**。
