# 10 · 指令大白话（一条一句）

> 不看编码，先看"这句话在干什么"。我们子集共 18 条。

**读一条指令,只问四件事**：做什么 · 用谁(rs1/rs2) · 结果放哪(rd) · 有没有常量(imm)。

---

## 算术 / 逻辑（R 型：读两个寄存器，写 rd）
| 指令 | 大白话 |
| --- | --- |
| `add  x5,x6,x7` | x5 = x6 + x7 |
| `sub  x5,x6,x7` | x5 = x6 - x7 |
| `and  x5,x6,x7` | x5 = x6 & x7（按位与） |
| `or   x5,x6,x7` | x5 = x6 \| x7（按位或） |
| `xor  x5,x6,x7` | x5 = x6 ^ x7（按位异或） |
| `slt  x5,x6,x7` | x5 = (x6 < x7) ? 1 : 0（有符号比较） |

## 立即数运算（I 型：读一个寄存器 + 常量，写 rd）
| 指令 | 大白话 |
| --- | --- |
| `addi x5,x6,10` | x5 = x6 + 10 |
| `andi x5,x6,10` | x5 = x6 & 10 |
| `ori  x5,x6,10` | x5 = x6 \| 10 |
| `xori x5,x6,10` | x5 = x6 ^ 10 |
| `slti x5,x6,10` | x5 = (x6 < 10) ? 1 : 0 |

## 访存（地址 = 基址寄存器 + 立即数偏移）
| 指令 | 大白话 |
| --- | --- |
| `lw x5, 8(x6)` | x5 = 内存[x6 + 8]（读 4 字节到 x5） |
| `sw x5, 8(x6)` | 内存[x6 + 8] = x5（把 x5 写进内存） |

> `lw`/`sw` 都用 `rs1` 当基址、`imm` 当偏移；`8(x6)` 读作"x6 加 8 那格内存"。

## 分支（比较结果决定 PC 往哪走）
| 指令 | 大白话 |
| --- | --- |
| `beq x5,x6,L` | 如果 x5 == x6，就跳到 L |
| `bne x5,x6,L` | 如果 x5 != x6，就跳到 L |

> 硬件里常用"相减看结果是否为 0"来判断相等 → 这就是 ALU 的 `zero` 的用途。

## 跳转
| 指令 | 大白话 |
| --- | --- |
| `jal  ra, L` | ra = PC + 4（存返回地址）；PC = PC + L（跳过去） |
| `jalr x5, 8(x6)` | x5 = PC + 4；PC = x6 + 8（跳到寄存器给的地址 + 偏移） |

> `jal`：目标 = PC + 立即数（写死在指令里）；`jalr`：目标 = 寄存器 + 立即数（灵活，常用于函数返回）。

## 高位立即数（构造大常数 / 算地址）
| 指令 | 大白话 |
| --- | --- |
| `lui  x5, 0x12345` | x5 = 0x12345 << 12 |
| `auipc x5, 0x12345` | x5 = PC + (0x12345 << 12)（PC 相对地址） |

> `lui` + `addi` 合起来能构造任意 32 位常数。

---

## 四类映射到数据通路

| 类别 | 用到的部件 |
| --- | --- |
| 算术/逻辑/立即数 | RegFile 读 → **ALU** 算 → 写 RegFile |
| 访存 lw/sw | RegFile 读 → ALU 算地址 → **DMEM** 读/写 |
| 分支 beq/bne | RegFile 读 → ALU 相减 → 改 **PC** |
| 跳转 jal/jalr | 生成目标地址 → **PC**；写返回地址 → RegFile |
| lui/auipc | ALU/立即数 → 写 RegFile |

**一句话**：指令 = 告诉 CPU「用哪些寄存器、做什么运算、结果放哪、要不要改 PC」。
