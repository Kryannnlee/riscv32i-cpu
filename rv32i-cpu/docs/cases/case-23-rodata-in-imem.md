# Case 23 · C 里的字符串字面量读不到（哈佛结构的代价）

> **代码来源**：原始　**严重程度**：静默（能编译、能链接、能跑，输出是垃圾）　**阶段**：C 程序

---

## 1. 现象

只要 C 程序里出现字符串常量，读到的就是垃圾：

```c
#include <stdio.h>
puts("Hello");
```

反汇编里能看到编译器把 `"Hello"` 放进了 `.rodata`，然后生成一条 `lw` 去读它。
但硬件上读回来的是**另一块内存里的内容**，不是字符串。

更麻烦的是：**不报错、不崩溃**，只是输出乱码或者别的数据。

## 2. 当时的代码

`sw/link.ld`（最初的版本）：

```ld
SECTIONS
{
    .text : {
        KEEP(*(.text.start))
        *(.text*)
        *(.rodata*)        /* ← 字符串被放在这里，也就是 IMEM */
    } > IMEM

    .data : { ... } > DMEM
}
```

而 CPU 的访存通路是：

```systemverilog
// cpu_pipe.sv MEM 段
dmem dmem_i ( .addr(ex_mem_alu_result), .rd_data(mem_rdata), ... );
// 所有 lw/lb/lh 都只走 dmem，没有任何一条通路能读 imem
```

## 3. 为什么错：哈佛结构

我们的 CPU 是**哈佛结构**：

| 存储器 | 谁访问 | 地址范围 |
| --- | --- | --- |
| `imem` | **只有取指单元（IF）** | 0x0000 ~ 0x0FFF |
| `dmem` | **只有访存指令（lw/sw 等）** | 0x1000 ~ 0x1FFF |

两条路**完全独立**。`lw` 指令把地址送到 dmem，**永远不会去 imem**。

所以 `.rodata` 放在 IMEM，编译器生成的 `lw` 读它时，实际读的是 dmem 里同一地址的内容——
那里面可能是栈、可能是别的变量、也可能是 0。

冯·诺依曼结构（统一编址）不会有这个问题，但在 FPGA 上指令和数据分成两块 RAM 更简单、也更快（IF 和 MEM 能同拍访问）。

## 4. 怎么定位的

**这次没有真正踩到**，是在写第一个 C 程序之前就看出来了：

- 编译出来的 `.rodata` 段在地址 0x0 附近
- CPU 的 lw 只连 dmem，而 dmem 从 0x1000 开始
- 两者根本不相交

于是 `main.c` 里**一个字符串都没有用**，全部改成字符常量：

```c
putc_('S'); putc_('U'); putc_('M'); putc_('=');
```

## 5. 修正后的代码

**临时方案（当前）**：不用字符串。

```c
/* ❌ 不能这样写 */
puts("SUM=");

/* ✅ 这样写 */
putc_('S'); putc_('U'); putc_('M'); putc_('=');
```

**正式方案（待做，任务 #2）**：把 `.rodata` 挪到 DMEM，并在启动时把数据段装进 dmem。

```ld
/* 数据段全部放 DMEM */
.rodata : { *(.rodata*) } > DMEM
.data   : { *(.data*)   } > DMEM
```

```systemverilog
/* dmem 增加一个数据段初值文件 */
initial begin
    for (int i = 0; i < 1024; i++) mem[i] = 32'd0;
    $readmemh("sw/prog_data.hex", mem);   // 从 0x1000 起的数据段
end
```

这样 `lw` 就能真正读到字符串了。代价是多一个 hex 文件和一次加载。

## 6. 怎么防止再犯

| 做法 | 说明 |
| --- | --- |
| **写 C 之前先确认内存模型** | 指令和数据是分开的还是统一的？地址怎么划分？ |
| **看 `.dis` 里有没有指向低地址的 `lw`** | 0x0~0xFFF 的 `lw` 基本都是错的（那是 IMEM 的范围） |
| **链接脚本和 RTL 的内存范围必须对得上** | `.text` @ 0x0 + `.data` @ 0x1000 ↔ imem 4KB + dmem 4KB |
| **字符串是最容易中招的**，其次是 `const` 数组、switch 跳转表 | 它们都会进 `.rodata` |

## 7. 一句话记忆

> **哈佛结构里，`lw` 读不到 `.text` 里的东西。**
> 字符串、常量数组、跳转表——只要进了 `.rodata`，就得先问"它在哪块内存"。
