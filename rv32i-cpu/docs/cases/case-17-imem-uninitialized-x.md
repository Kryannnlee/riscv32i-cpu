# Case 17 · imem 没初始化的位置是 X，程序跑完后 PC 变成 X，LED 亮着不闪

> **代码来源**：原始　**严重程度**：致命且只在板上暴露（仿真全绿）　**阶段**：首次上板

---

## 1. 现象

烧进板子后：

- D4（DONE）常亮 —— 配置成功
- **D9（`FPGA_LED0`，心跳灯）常亮，不闪**

心跳逻辑是 `led[0] = pc[22]`，50MHz 下应该约 6Hz 闪烁。
常亮意味着 `pc[22]` 恒定不变——但 PC 怎么会不动？

（更迷惑的是：它不是"完全不亮"，而是"亮着"。看起来像"跑起来了但卡住"，其实根本没跑。）

## 2. 当时的代码

`imem.sv`：

```systemverilog
logic [31:0] mem [0:255];      // 256 个字

initial begin
    mem[0] = 32'h00500093;
    mem[1] = 32'h00108133;
    ...
    mem[27] = 32'h12345A37;    // 只初始化了 0~27
end                             // mem[28]~mem[255] 是 X
```

## 3. 为什么错

三层原因叠加：

**① 仿真里 X 不会暴露**
测试只检查前 28 条指令，跑完就 `$finish`，从没读到 `mem[28]` 之后。

**② 综合器把 X 当 don't care**
未初始化的位置"内容随便"，Vivado 就可以自由优化。综合报告里能看到：

```
ROM: Preliminary Mapping Report
|imem | mem | 32x29 | LUT |
```

**声明的是 256×32，实际只实现成 32×29。**

**③ 程序跑完后 PC 冲进未定义区**
程序在第 28 条结束（PC=112），继续取指 → 读到优化后的垃圾 →
`instr` 是 X → `decoder` 输出 X → `branch_taken` X →
`next_pc` X → **PC 变成 X** → `pc[22]` 是 X → LED 亮着不动。

## 4. 怎么定位的

**不是靠猜，是靠读综合报告。**

1. 先确认引脚没问题（对照厂商给的 xdc：U18/T19/T10 全对）
2. 于是问题在设计里，而且是"时钟没跑"或"逻辑卡住"
3. 翻综合日志，注意到 `ROM: 32x29` 这一行——**和我们声明的 256×32 对不上**
4. 反推：只有未初始化的存储被压缩才会这样

## 5. 修法

在 `initial` 块开头把所有位置先填成 NOP：

```systemverilog
initial begin
    for (int i = 0; i < 256; i++)
        mem[i] = 32'h00000013;   // addi x0, x0, 0 = NOP

    mem[0] = 32'h00500093;       // 再覆盖测试程序
    ...
end
```

修完：程序跑完之后永远执行 NOP，PC 持续递增，心跳灯正常闪。

（另一种写法：在程序末尾放 `jal x0, 0` 自跳转，锁在原地。但那样 PC 不动，心跳也会停。）

## 6. 怎么防止再犯

- **存储器的每一个位置都要有确定值。** 尤其是 ROM/查找表。
- 上板前扫一眼综合报告的 `ROM/RAM Mapping Report`，核对深度和位宽是否和 RTL 一致。
- 仿真加一条：跑足够多周期，确认 PC 不会变成 X。
- 记住这条经验：**"仿真全绿"和"上板能跑"之间，隔着综合器的一堆优化。**

## 7. 一句话记忆

> X 不是"零"，是"随便"，综合器会拿它做优化。
> **存储器没填满，程序跑完之后就没有路可走了。**

## 补记（2026-11-04）：`dmem` 是同一个问题

加字节访存时又遇到一次：

```
FAIL  x26 = X   期望 291
```

程序用 `sb` 只写了地址 20、21 两个字节，然后用 `lw` 读回整字。
地址 22、23 从没写过 → 是 X → `lw` 读出的整字也是 X。

**同样的修法**：`dmem` 加一段 `initial` 清零所有 256 个字。

```systemverilog
initial begin
    for (int i = 0; i < 256; i++)
        mem[i] = 32'd0;
end
```

真实程序里这一步由 `crt0` 清零 `.bss` 完成；仿真和上板这里直接给初值。

**教训升级**：不只是 ROM，**任何存储器**都要有确定的初值。
"只写一部分字节、再按整字读"这种用法，最容易暴露未初始化的问题。
