【解码后的文本】
Microseconds for one run through Dhrystone: 23
Dhrystones per Second:                      43029

【换算】
DMIPS      = 43029 / 1757 = 24.5
DMIPS/MHz  = 24.5 / 50     = 0.49

【说明】
- 计时来源是 MMIO 0x800C 的周期计数器（每拍 +1），
  经 CYCLES()/50 换算成微秒后交给 Dhrystone。
- Dhrystone 自带的 Microseconds 公式在 HZ=50e6 时会 32 位溢出，
  所以改了计时单位（见 sw/bench/dhrystone.h 的注释）。
- 仿真与板上结果一致：计时器数的是周期数，与仿真时钟快慢无关。
