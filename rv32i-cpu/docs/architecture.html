2b · 五个阶段的含义（IF / ID / EX / MEM / WB）

阶段干什么涉及模块产出
IF 取指用 PC 从指令内存取 32 位指令；同时算 PC+4pc, imem, adderinstr, pc
ID 译码指令→控制信号；读寄存器 rs1/rs2；生成立即数decoder, regfile(读), imm_gen控制信号, rs1_data, rs2_data, imm
EX 执行ALU 运算；算访存地址；分支相减判断alu, alu_ctrl, ALUSrc MUXalu_result, zero
MEM 访存仅 LW/SW 动内存（其它空过）dmemmem_rdata
WB 写回把结果写回寄存器 rd（ALU/内存/PC+4 三选一）regfile(写), WB MUX寄存器更新
指令IFIDEXMEMWB
addi x5,x6,10取指译码x6+10—写 x5
lw x5,8(x6)取指译码算地址读内存写 x5
beq x5,x6,L取指译码x5−x6——
记忆：取指(去拿) → 译码(看懂) → 执行(算) → 访存(存取内存) → 写回(存回寄存器)
