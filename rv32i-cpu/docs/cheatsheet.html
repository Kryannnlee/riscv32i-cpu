指令大白话（18 条）

指令做什么
add x5,x6,x7x5 = x6 + x7
subx5 = x6 - x7
and/or/xorx5 = x6 ⊙ x7（按位）
slt x5,x6,x7x5 = (x6<x7)?1:0 有符号
addi x5,x6,10x5 = x6 + 10
andi/ori/xori同上，按位
slti x5,x6,10x5 = (x6<10)?1:0
lw x5,8(x6)x5 = 内存[x6+8]
sw x5,8(x6)内存[x6+8] = x5
beq x5,x6,Lx5==x6 → PC=PC+L
bne x5,x6,Lx5!=x6 → PC=PC+L
jal ra,Lra=PC+4; PC=PC+L
jalr x5,8(x6)x5=PC+4; PC=x6+8
lui x5,0x12345x5 = 0x12345<<12
auipc x5,0x12345x5 = PC+(0x12345<<12)

指令类别 → 数据通路

  • 算术/逻辑/立即数：RegFile 读 → ALU → 写 RegFile
  • lw/sw：RegFile 读 → ALU 算地址 → DMEM 读/写
  • 分支：ALU 相减 → zero → 改 PC
  • 跳转：算目标 → PC；写返回地址 → RegFile
  • lui/auipc：立即数/PC → 写 RegFile

Verilog / 概念 速记

  • 组合：assign / always_comb（用 =）
  • 时序：always_ff @(posedge clk)（用 <=，读旧值一起更新）
  • case 要写 default，否则出 latch
  • 位宽不匹配：窄→宽补 0，宽→窄截断（不报错）
  • RISC-V 是 小端：0x00A30293 存内存 = 93 A3 02 00
  • x0：读恒 0，写忽略
  • 常用：32'h... 4'b0000；拼接 {a,b}；复制 {n{x}}
